# Project 7: CI Validation for Terraform

## Goal

Automate Terraform validation checks using GitHub Actions.

## Workflow

The workflow runs automatically whenever files in project7 are pushed.

The pipeline performs:

- terraform init
- terraform fmt -check
- terraform validate

## Deliverables

- GitHub Actions Workflow
- Pipeline Screenshot
- Workflow Badge

## Skills Demonstrated

- Terraform
- GitHub Actions
- CI/CD
- Infrastructure as Code
